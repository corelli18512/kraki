# Localization glossary (English → 简体中文)

Draft — to be reviewed by the product owner. Every client uses these terms.

## Style

- Tone: plain, short, friendly; address the user as “你” (not “您”).
- Full-width Chinese punctuation (，。：；？！“”（）), half-width for code,
  paths, shortcuts and numbers. Space between Chinese and Latin words/numbers
  (`5 个会话`, `打开 Kraki`) — except Intl/system formatters' own output
  (“5分钟前”).
- Ellipsis “…” stays for in-progress states (“正在连接…”) and menu items
  that open a dialog (“设置…”).
- Buttons are verbs (“重试”, “删除会话”); avoid “点击这里”.
- Keep `⌘ ⌥ ⌃ ⇧`, F-keys and `Ctrl`/`Alt`/`Win` as is.
- Keep keyboard shortcut hints, code, file names, model names, agent output,
  and anything the user typed untranslated.
