3. 客户端附件状态机（改造后）

stateDiagram-v2
  [*] --> Unknown
  Unknown --> Cached: 磁盘命中
  Unknown --> Queued: 用户打开 / 可见 300 ms
  Queued --> Waiting: 未认证 / 重连中
  Waiting --> Queued: 认证完成
  Queued --> InFlight: 调度器选中（优先级最高）
  InFlight --> InFlight: 收到第 n 块 → 请求 n+1
  InFlight --> Paused: 被更高优先级抢占
  Paused --> Queued
  InFlight --> Queued: 块超时 / 断线（保留已收块）
  InFlight --> Ready: 最后一块
  Queued --> Unknown: 离开屏幕（取消）
  Ready --> Cached
  Cached --> [*]
  InFlight --> Failed: not_found / too_large
  Failed --> Queued: 用户点重试
