3. Client attachment state machine (after the rework)

stateDiagram-v2
  [*] --> Unknown
  Unknown --> Cached: disk hit
  Unknown --> Queued: user opened / visible 300 ms
  Queued --> Waiting: not authenticated / reconnecting
  Waiting --> Queued: authenticated
  Queued --> InFlight: picked by scheduler (highest priority)
  InFlight --> InFlight: chunk n received → request n+1
  InFlight --> Paused: preempted by higher priority
  Paused --> Queued
  InFlight --> Queued: chunk timeout / disconnect (keeps received chunks)
  InFlight --> Ready: last chunk
  Queued --> Unknown: off screen (cancel)
  Ready --> Cached
  Cached --> [*]
  InFlight --> Failed: not_found / too_large
  Failed --> Queued: user taps Retry
