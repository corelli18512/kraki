# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

- Preferred: [report privately on GitHub](https://github.com/corelli18512/kraki/security/advisories/new).
- Or email **corelli@corelli.cloud**.

Include what you found, how to reproduce it, and which apps or versions are affected. You'll get an
acknowledgement within a few days. Please give us reasonable time to fix the problem before
disclosing it publicly; we'll credit you in the release notes if you'd like.

## Supported versions

Fixes go into the latest release of each app (Kraki for Mac, the iPhone app, Kraki for Windows,
the web app and the `kraki` command-line version) and the hosted service. Please check that the
problem still happens on the latest release.

## Scope

What Kraki protects, and what it doesn't, is described in the [security model](docs/security.md).
Your own computers, your coding agents and their model providers are outside Kraki's control.
