# Kraki for iPhone 0.1.38

- Images load faster. Several images now download together when your connection is fast, and loading starts sooner after an image scrolls into view. On a slow connection images still load one piece at a time, so chat stays responsive.
- You can open an image before it has finished loading. The viewer shows its progress and the picture appears in place when it arrives.
- When a message has several images, you can swipe through all of them in the viewer, including ones that are still loading.
- When the agent asks a question while other tools are still running, the chat shows only the question. Before, a second "tools running" bubble appeared under it.
- New Session list header. The Kraki title floats over the list without a gray band, and the Preview badge is gone.
- Search Sessions by title, computer, model, last message or the start of a Session ID.
- Filter the Session list by computer. This appears when you have more than one computer.
- Swiping a Session now shows Pin and Mark as Read/Unread. Fork is still in the Session info sheet.
