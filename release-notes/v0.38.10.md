# Kraki CLI 0.38.10

- New `kraki build-info` and `kraki build-info --json` commands show this binary/package's source commit, GitHub Run ID and build provenance links.
- Available in the Linux, macOS and Windows binaries and the npm package. `kraki --version` keeps its existing output.
- Release downloads now include `release-manifest.json` and `provenance.json` in addition to checksums. Publication verifies the repository, workflow, source and exact run/attempt.
- Local builds are explicitly labeled; runtime environment variables cannot replace the embedded build identity.

See [verification instructions](https://github.com/corelli18512/kraki/blob/v0.38.10/docs/BUILD_PROVENANCE.md). This is release provenance, not a reproducible-build or malware-free guarantee.
