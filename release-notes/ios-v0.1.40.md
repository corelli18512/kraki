# Kraki for iPhone 0.1.40

- New Session ends in the chat composer: tap +, type or dictate, and send. The session starts with that as its first message; there is no separate Create step. Dictated text appears as the first bubble and is corrected there, as on the Mac. The Device, Agent and Title rows are unchanged.
- Opening a Session with a red dot lands on the start of the latest reply again, when the reply is longer than a screen.
- Your GitHub avatar loads from GitHub's image server directly, so it also shows on networks where github.com is unreachable.
- Settings › About groups the app's version with its build record, separately from the relay.
- Devices shows Accounts only when a subscription has reported usage, below the computer list.
