# Kraki CLI 0.39.1

- **Images that agents show**: `show_image` (Claude, Copilot, Codex) now reads the image type from the file's contents instead of its extension. A PNG or WebP saved as `.gif` no longer reaches the model and the apps labelled as a GIF. A file that is not a PNG, JPEG, GIF or WebP is refused with a clear error for the agent. Agents are no longer told that GIFs can't be animated.
- Small animated GIFs with many frames are passed on unchanged instead of being re-encoded, so they keep every frame.
- **Updating Kraki for Windows from your other devices**: the Kraki built into Kraki for Windows can now update the app. It downloads the installer of the newest Kraki for Windows release, checks it against that release's checksums, runs it silently and waits for the new version to come online. This works for an install made just for one user, which is the default. An install for all users reports that it can't be updated remotely, and your apps show how to update it by hand.
- Downloads for an update now resume where they stopped when the connection drops or stalls, instead of failing; this matters for big downloads on a slow link. `kraki update` shows "Download interrupted at N%; resuming in Ns…" while it waits to retry.
- Update checks for Kraki for Mac follow the app's update channel in Settings › Updates and compare build numbers, so a Mac on a Dogfood build is offered the next build, including the formal release, and can be updated from your phone.
