# Kraki for Windows 0.1.6

Windows 10/11 x64 preview, including Kraki CLI 0.38.10. A Windows look for the app.

- The title bar is part of the app: the session title and its mode sit at the top left, with Windows' own minimize, maximize and close at the top right.
- Session mode (Safe / Auto / Delegate) opens as a Windows dropdown next to the title.
- Settings has a left-hand navigation and rounded cards.
- Notification icons are smooth instead of jagged.

This preview installer is still not Authenticode-signed. Windows may display SmartScreen warnings. GitHub build provenance is a separate verification mechanism and does not remove those warnings.

[How to verify the installer](https://github.com/corelli18512/kraki/blob/win-v0.1.6/docs/BUILD_PROVENANCE.md).
