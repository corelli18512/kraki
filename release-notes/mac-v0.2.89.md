# Kraki for Mac 0.2.89

- Images load faster. Several images now download together when your connection is fast. On a slow connection images still load one piece at a time, so chat stays responsive.
- You can open an image before it has finished loading. The viewer shows its progress and the picture appears in place when it arrives.
- When a message has several images, you can page through all of them in the viewer, including ones that are still loading.
- When the agent asks a question while other tools are still running, the chat shows only the question. Before, a second "tools running" bubble appeared under it.
- Sidebar search also matches the start of a Session ID, and ignores accents.
