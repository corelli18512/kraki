# Kraki for iPhone 0.1.42

- Simplified Chinese: Kraki follows your iPhone language, or choose one per app in Settings.
- Two-column layout on wide screens, including iPhone Duo unfolded and iPad windows. Folding and unfolding keeps your reading position and reflows bubbles; the image viewer stays on the right image.
- Rename any of your devices from Devices; the new name shows on every device.
- Chats that don't fill the screen load older history automatically.
- Dismissing New Session while dictating stops the microphone; if creating a session fails, the first message you typed goes back into the box.
- A keyboard answer to a permission or question waits for a voice message that is still being corrected.
- The live card updates when the number of running tools changes; whitespace-only drafts no longer show as a bubble.
- Session search: the clear button works while typing with a Chinese input method.
- Devices: the Update section no longer gets stuck if a computer goes offline during an update, and Remove Device stays available.
- Steadier swipe actions and faster session list reordering; faster reconnects.
