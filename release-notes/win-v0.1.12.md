# Kraki for Windows 0.1.12

- **Download and copy chat images**: the image viewer has a **Download** button, and right-clicking an image in a chat or in the viewer offers **Download Image** and **Copy Image**. Download saves the original file under the image's name, so a GIF stays an animated GIF. Copy Image copies a picture (for a GIF, its first frame).
- A GIF without a loop count loops forever. An attached image is recognised as a GIF by its contents, not its file name.
- **Updates from your other devices**: from this version on, your phone or Mac can update Kraki for Windows for you when it was installed just for you, which is the default. The installer is downloaded, checked and run silently, and Kraki starts again on the new version. While the installer runs, Kraki quits without asking and without taking this PC offline. An install for all users shows how to update it by hand.
- Device updates name Kraki for Windows and Kraki for Mac with their own versions, put versions in the right order, and say whether an update of either app finished.
- Built-in Kraki 0.39.1: every change in [Kraki CLI 0.39.1](https://github.com/corelli18512/kraki/releases/tag/v0.39.1).
