# Kraki for Windows 0.1.9

- Simplified Chinese: Kraki follows your Windows language, or choose one in Settings.
- Rename any of your devices; the new name shows on every device, and conversations update their computer name even after an offline rename.
- Chat: older history no longer skips messages after the computer's Kraki restarts; a message that keeps being refused is not sent twice and its error shows once; "Loading history…" appears only while history is actually fetched; renaming the open conversation no longer adds a Back step.
- When creating a conversation fails, the first message you typed is put back into the box.
- Chinese and other input methods: Enter/Esc while choosing a candidate no longer saves or closes the session title, custom words or table search.
- Security: the desktop bridge only answers Kraki's own pages, GitHub sign-in opens in its own window, and only https links open in the browser.
- Starting, stopping or updating the command-line Kraki shows a clear error with the CLI's own last line, never a raw "Command failed" message.
- The window reopens on the display that held most of it.
- Performance data is more accurate (already-current openings, reconnects, sleep and wake), and the one-time notice no longer takes keyboard focus.
- Faster reconnects.
