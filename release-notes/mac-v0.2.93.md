# Kraki for Mac 0.2.93

- **Save and copy chat images**: right-click an image in a chat or in the image viewer and choose **Save Image…** or **Copy Image**. Both are also in the viewer's toolbar. You get the original file under the image's name, so a GIF stays an animated GIF.
- **Animated GIFs play** in chats and in the viewer, and the viewer has Play/Pause. A GIF without a loop count loops forever. With Reduce Motion on, a GIF shows its first frame until you play it.
- **Sending GIFs**: a GIF you drop, paste or attach is sent as a GIF instead of being turned into a still picture. A GIF that is too large is made smaller and stays animated. While it is being prepared, the image slot shows that it is loading and Send waits; × cancels it.
- Devices show a PC running Kraki for Windows by the app's name and version. Once it runs Kraki for Windows 0.1.12 or later, you can update it from this Mac.
- Built-in Kraki 0.39.1: every change in [Kraki CLI 0.39.1](https://github.com/corelli18512/kraki/releases/tag/v0.39.1).
