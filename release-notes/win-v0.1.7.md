# Kraki for Windows 0.1.7

Windows 10/11 x64 preview, including Kraki CLI 0.38.10.

- **Share Performance Data**, as on Mac and iPhone: Kraki sends timings such as how long messages take to deliver and replies to start, connection drops and how long opening the app or a conversation takes, so we can find problems and make Kraki better. Never message text, drafts, voice, attachments or file names. A one-time notice after sign-in lets you choose OK or Don't Share; you can change it anytime in Settings › General › Privacy. Turning it off deletes unsent performance data.
- Answering a Pi question can include an image, or be just an image. Claude, Copilot and Codex questions take text only: the image stays in the composer for your next message.

This preview installer is still not Authenticode-signed. Windows may display SmartScreen warnings. GitHub build provenance is a separate verification mechanism and does not remove those warnings.

[How to verify the installer](https://github.com/corelli18512/kraki/blob/win-v0.1.7/docs/BUILD_PROVENANCE.md).
